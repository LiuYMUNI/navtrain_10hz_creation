# Data licensing and credentials

This repository contains recreation code and small metadata/configuration
artifacts only. It does not grant rights to NAVSIM, OpenScene, or nuPlan data.
Users must obtain source data through the official channels and comply with
their terms.

Never commit dataset credentials, subscription URLs, personal access tokens,
SSH private keys, raw sensor files, native databases, generated packs, or
large SQLite indexes. Use environment-local configuration and dedicated SSH
keys with the minimum required access.
